# 第三方登录实施清单

## 阶段 0：产品与安全确认

- [x] 首期提供方选择飞书。
- [x] 首期账号模式选择“绑定已有账号”。
- [x] 不通过邮箱、手机号或姓名自动绑定。
- [x] 本地用户继续承载审批、禁用、组织和权限。
- [ ] 确认允许登录的飞书租户 `tenant_key`。
- [ ] 创建开发、测试环境飞书应用并登记回调地址。
- [ ] 确认解除绑定是否立即注销该用户的全部现有会话。
- [ ] 确认管理员是否可以代用户撤销绑定，以及审计保留期限。

## 阶段 1：通用服务端骨架

- [x] 增加第三方登录配置结构和生产环境启动校验。
- [x] 增加 provider 接口、注册表和公开的 provider 元数据接口。
- [x] 增加 `externalIdentities`、`oauthLoginAttempts`、`oauthLoginTickets` 类型。
- [x] 同时增加 SQLite 和 PostgreSQL 建表/迁移及重复执行测试。
- [x] 在完整备份中加入长期身份表；临时 OAuth 表不进入用户数据导出。
- [x] 增加 OAuth 专用速率限制、敏感字段日志约束和过期事务清理。

## 阶段 2：飞书服务端实现

- [x] 创建飞书授权 URL，使用强随机且单次消费的 `state`；官方换票接口明确支持后再启用 PKCE S256。
- [x] 校验回调 `state`、用途、有效期、单次消费和允许租户。
- [x] 用授权码交换访问令牌并获取用户信息。
- [x] 生成规范的 `providerSubject=tenant_key:open_id`。
- [x] 登录用途使用完访问令牌后立即丢弃，不保存 refresh token。
- [x] 实现已有账号绑定、精确身份登录、解除绑定和管理员撤销。
- [x] 登录成功后仍执行本地用户审批、禁用和会话版本校验。
- [x] 回调只返回一次性登录票据，由前端换取本项目 JWT。

## 阶段 3：前端体验

- [x] 登录页根据 `/api/auth/providers` 动态显示“使用飞书登录”。
- [x] 增加回调页，处理成功、用户取消、未绑定、租户不允许和服务异常。
- [x] 个人设置增加“登录方式”，显示提供方、身份摘要、绑定时间和最后登录时间。
- [x] 解除绑定有明确确认提示；绑定操作由用户主动点击发起。
- [x] 首期所有用户均保留本地密码，因此解除飞书后仍可登录。
- [x] 组织用户管理中增加外部身份状态和管理员撤销入口。
- [x] 飞书异常时保留本地账号密码登录。

## 阶段 4：测试

### 单元测试

- [ ] 配置开关、缺失配置和生产环境安全校验。
- [x] `state` 哈希、重放和用途隔离。
- [x] 允许租户与拒绝租户。
- [x] `providerSubject` 生成和唯一约束。
- [ ] 未绑定、已绑定、已撤销、未审批和已禁用用户登录。
- [x] 一次性票据重放保护和本地用户状态复核。
- [x] 解除飞书后不能继续使用该身份登录。

### 集成测试

- [ ] 用 mock HTTP 服务补齐用户拒绝授权、飞书错误码和超时场景（成功与租户拒绝已覆盖）。
- [x] 验证身份表和完整备份中没有授权码或飞书令牌。
- [ ] SQLite 与 PostgreSQL 都运行迁移和认证集成测试。
- [x] 验证完整备份包含长期身份绑定，且不导出临时凭证。
- [ ] 验证本地账号密码登录在第三方服务不可用时正常工作。

### 手工验收

2026-07-16 已用隔离 SQLite 实例和虚拟应用凭据完成本地 API 验收：默认关闭不公开提供方；启用后正确生成官方授权域名、App ID、回调地址和随机 `state`，授权 URL 不包含 App Secret，站外返回地址被拒绝。

- [ ] 已有用户绑定飞书后可登录同一用户，权限和数据不变。
- [ ] 未绑定飞书账号不会自动创建或误绑用户。
- [ ] 非允许租户无法绑定和登录。
- [ ] 用户取消授权后可正常返回并重新尝试。
- [ ] 解除绑定有二次确认，解除后不能再用该飞书身份登录。
- [ ] 管理员可定位并撤销异常绑定，审计信息完整。

## 阶段 5：上线

- [ ] 为生产环境创建独立飞书应用和 HTTPS 回调地址。
- [ ] 使用密钥管理系统注入 App Secret 和事务加密密钥。
- [ ] 先在少量内部账号开放，观察成功率、失败类型和审计事件。
- [ ] 准备关闭 `FEISHU_LOGIN_ENABLED` 的快速回退方式，不影响本地登录。
- [ ] 形成管理员处理“换飞书账号、误绑、员工离职、租户迁移”的操作说明。

## 暂不实施

- 首次飞书登录自动创建已审批用户。
- 按邮箱或手机号自动合并账号。
- 自动赋予组织角色或列表权限。
- 保存飞书 refresh token。
- 通讯录、部门和组织结构同步。
- 用飞书 access token 替代本项目 JWT。
