# 更新日志

## 未发布

- phoenix-wing 前后端依赖固定为 npm `0.3.0`，移除相邻仓库源码自动探测和 Vite 本地 alias，避免 Wing 后续本地改动影响 Open Issue。
- 新增可配置的飞书 OAuth 登录：支持已有账号绑定/解绑、单次 `state` 与登录票据、租户白名单、登录方式设置、管理员撤销、SQLite/PostgreSQL 表结构、备份和安全回归测试；默认关闭且不保存飞书访问令牌。
- 全面细化页面帮助与界面巡游，补齐组织、推送、功能表、设置和测试页导引；巡游自动跳过权限不足或当前标签不可见的步骤，并增加锚点一致性测试。
- 列表管理将「新建列表」前置到状态筛选之前；归档与取消归档均要求二次确认。
- 列表管理新增统一状态列和全部/正常/已归档/已删除视图；全部视图遵循当前用户访问权限，系统管理员可同时查看软删除记录；仪表盘和列表管理均支持归档确认与取消归档。
- 列表管理新增名称/描述/负责人搜索、列表类型筛选、结果计数与清除筛选，超过 30 条时提供 30/50/100 条前端分页。
- 问题列表改为前端统一搜索与筛选，补充优先级筛选、结果计数和清除筛选；超过 30 条时分页显示，并分批拉取列表全部 Issue，避免后端默认 50 条上限。
- 系统权限「查看」落实为全局只读上限；统一列表、Issue、点检和推送的读写权限，封堵按 ID 越权访问，并同步隐藏无权操作入口。
- 禁用、撤销审批和密码变更会立即撤销旧令牌；启动流程不再自动批准待审批账号。
- 列表/成员、Issue/主链接和推送审批关键写入增加事务与并发保护；新增 HTTP 权限与认证回归测试。
- 生产启动强制配置安全的 `JWT_SECRET` 和 `INITIAL_ADMIN_PASSWORD`。
- 点检时间线支持默认倒序、卡片/表格切换、Markdown 表格复制和完整编辑。
- 点检状态支持「已作废」，与业务性「已跳过」区分；SQLite 与 PostgreSQL 均包含旧库约束迁移。
- 新建点检弹窗突出显示所属 Issue 编号与标题，降低误建风险。
- Issue 详情宽屏采用内容与时间线双栏布局，详情弹窗扩展至页面 90% 宽度。
- 列表操作列统一为紧凑图标网格。

## v0.2.0（2026-07-09）

### 列表详情页

- **三视图列设置**：简单 / 复杂 / 跟踪 分别配置显示列与顺序（localStorage 持久化）
- **表格交互**：标题/编号点击查看详情；严重度、优先级、状态、关注、责任人等快速编辑弹窗
- **操作列**：🔍 详情 · ✏️ 编辑 · 📤 推送 · ⋮ 更多
- **关注度**：列表文字标签；弹窗/编辑内 `AttentionStars` 五星控件（可清零）
- **筛选**：「只显示【不关注】」纯前端筛选
- **排序**：关注列可排序；默认关注度降序 → 优先级（紧急优先）

### Issue 编辑

- 编辑弹窗补充 8D 字段（D3/D4/D5-D6）
- 编辑模式可改本列表关注度

### 数据与 API

- **关注系数** 替代 `voided`：`attentionLevel` 0~5
- 迁移后删除 `voided` / `voidedAt` / `voidedBy` 三列
- 移除 `includeVoided` 查询参数及 `PATCH .../void`、`PATCH .../unvoid`
- 统一使用 `PATCH .../attention`

### 其他

- 版本号升至 0.2.0（状态栏自动读取）
- 单元测试页（系统管理员）
- 文档：`Issue列设计`、`IssueListLink关注系数`、使用手册、API 参考
