# phoenix-open-issue 计划

## 项目定位

基于 phoenix-wing 框架搭建的 **Open Issue 管理应用**。作为 phoenix-wing 框架的首个应用案例，验证框架的复用性和完整性。

## 技术栈

- Vue 3 + TypeScript
- phoenix-wing（壳层框架 + 控件库）
- Element Plus
- Pinia
- Vite

## 架构思路

使用 phoenix-wing 的壳层组件搭积木：

```
PnwRibbonShell           ← Ribbon 功能区
├── PnwRibbonTabBar      ← 功能标签
├── PnwRibbonGroup        ← 按钮分组
│   └── PnwRibbonToolButton ← 工具按钮

PnwWorkbenchTabBar       ← 页面标签栏

PnwSidebarBlock          ← 侧栏块（筛选/属性/日志）
├── 筛选面板
├── 属性面板

PnwPageHeader            ← 页面标题

PnwAppModalOverlay       ← 弹窗
PnwChoiceDialogHost      ← 确认对话框
PnwAsyncProgressOverlay  ← 异步进度
```

## 应用功能

- Issue 列表（表格 + 筛选 + 排序）
- Issue 详情（属性面板）
- Issue 创建/编辑（对话框）
- 工作空间管理
- 批量操作
