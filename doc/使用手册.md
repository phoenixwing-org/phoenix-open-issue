# Open Issue List 使用手册

> 汽车行业 IATF 16949 / 8D 标准议题追踪系统

## 快速开始

```bash
pnpm run dev     # 启动 server(:3400) + web(:5181)
```

默认演示账号：`admin` / `zhangsan` / `lisi`，密码均为 `123456`。

Dashboard 点击「🗂️ 重置演示数据」可一键重建示例数据。

---

## 基本概念

### Issue List（议题列表）
按年/月/项目组织的议题集合。每个列表有独立的成员和权限。

### Issue（议题）
单个问题条目，包含 21 个汽车行业标准字段。

### Checkpoint（点检）
每个 Issue 下的时间线节点，记录处理进展。

### 推送
将 Issue 从一个列表推送到另一个列表（如小组→科室），需共同成员且目标列表负责人审批。

---

## 列表操作

### 创建列表
Dashboard → `+ 新建列表` → 填写名称、类型（年度/月度/项目/自定义）

### 查看列表
Dashboard 点击列表卡片进入。支持三种视图：

| 视图 | 用途 | 列 |
|------|------|-----|
| 📋 简单 | 点检会议快速扫视 | #, 标题, 严重度, 优先级, 责任人, 计划完成日, 状态 |
| 📋📋 复杂 | 审计追溯 | + 分类, 发现阶段, 提出人 |
| 📋📋📋 跟踪 | 跟踪讨论过程 | + 最近 3 条点检 (右锁定列) |

### 成员管理
列表页 → `成员` 按钮 → 添加/移除成员

角色：owner > admin > editor > reporter > viewer

### 归档列表
列表页 → 编辑 → 勾选「归档」→ 列表从 Dashboard 默认隐藏

---

## Issue 操作

### 新建 Issue
列表页 → `+ 新建 Issue`

填写汽车行业字段：
- **标题**（必填）
- **严重度**：致命/严重/一般/轻微
- **问题分类**：外观/尺寸/功能/过程/安全/其他
- **发现阶段**：来料检验/过程检验/终检/客户反馈/审核发现/供应商端
- **提出人 / 责任人**：从用户列表选择
- **计划完成日**：YYYY-MM-DD

### 查看 Issue
列表行点击 → Issue 详情页

展示：基本信息、人员与日期、关闭信息、8D 报告（D3-D6）、描述、点检时间线

### 变更状态
列表行 → `状态 ▾` → 选择目标状态

### 推送 Issue
- **列表行**：📤 图标 → 选目标列表 → 确认
- **详情页**：`推送` 按钮

### 删除 Issue
列表行 → `状态 ▾` → `删除`

---

## 点检操作

### 添加点检
Issue 详情页 → `+ 添加点检` → 日期 + 描述 + 负责人

### 标记完成
点检项 → `标记完成` / `取消完成`

### 逾期提醒
点检日期已过且未完成 → 高亮显示

---

## 推送审批

### 发起推送
Issue 详情页 → `推送` → 选目标列表 → 确认

### 审批推送
1. 目标列表页出现黄色提示条
2. 点击「接受」→ Issue 复制到本列表
3. 点击「拒绝」→ 填写理由

也可在「推送历史」页面统一审批。
