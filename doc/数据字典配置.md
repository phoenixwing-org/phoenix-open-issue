# 数据字典配置

数据字典用于定义 Issue 的下拉选项枚举值，共 5 个分组。管理员可在「设置 → 数据字典」页面管理。

## 分组说明

| 分组 | 用途 | 影响范围 |
|------|------|----------|
| **问题分类** (issueCategory) | Issue 类别，如功能/外观/安全等 | Issue 创建/编辑、列表筛选 |
| **发现阶段** (detectionPhase) | 问题在哪个阶段发现 | Issue 创建/编辑、详情展示 |
| **组织类型** (orgUnitType) | 组织节点类型 | 组织架构管理 |
| **严重度** (severity) | 问题严重程度 | Issue 创建/编辑、列表筛选 |
| **关闭理由** (closeReason) | 关闭 Issue 时的原因 | Issue 关闭操作 |

## 预设方案

点击「设置 → 数据字典」页面的预设按钮，可快速追加推荐值（跳过已存在的项）。

### 🚗 汽车默认值

适合汽车制造/IATF 16949 质量管理场景。系统初始化时自动写入。

**问题分类 (6)**

| 值 | 显示名 | 说明 |
|----|--------|------|
| `appearance` | 外观 | 表面、色泽、装配间隙等可见缺陷 |
| `dimension` | 尺寸 | 尺寸超差、配合不良 |
| `function` | 功能 | 功能失效、性能不达标 |
| `process` | 过程 | 工艺执行偏差、流程不符 |
| `safety` | 安全 | 安全相关，需最高优先级处理 |
| `other` | 其他 | 未分类问题 |

**发现阶段 (6)**

| 值 | 显示名 | 说明 |
|----|--------|------|
| `incoming` | 来料检验 | IQC 进货检验发现 |
| `in_process` | 过程检验 | IPQC 制程巡检发现 |
| `final` | 终检 | FQC/OQC 最终检验发现 |
| `customer` | 客户反馈 | 客诉/客户退货/0km |
| `audit` | 审核发现 | 内审/外审不符合项 |
| `supplier` | 供应商端 | 供应商端发现并反馈 |

**严重度 (4)**

| 值 | 显示名 | 说明 |
|----|--------|------|
| `fatal` | 致命 | 涉及安全/法规/批量停线 |
| `major` | 严重 | 功能丧失/性能大幅下降 |
| `minor` | 轻微 | 部分功能受限，不影响使用 |
| `trivial` | 一般 | 轻微外观/体验问题 |

**关闭理由 (5)**

| 值 | 显示名 |
|----|--------|
| `completed` | 已完成 |
| `cancelled` | 已取消 |
| `duplicate` | 重复 |
| `transferred` | 已转交 |
| `unreproducible` | 不可复现 |

## 标签系统

每个字典项都有一个「标签」列，用于标记来源预设。支持多标签（逗号分隔）。

| 标签 | 含义 |
|------|------|
| `automotive` | 来自汽车默认值预设 |
| `software` | 来自软件默认值预设 |
| 空 | 手动添加的条目 |

**标签行为：**
- 点击预设按钮追加新项时 → 打上对应标签
- 预设值已存在但无该标签 → 追加标签（不重复插入）
- 预设值已有该标签 → 跳过
- 手动添加的条目 → 标签为空

## 删除保护

删除字典项时，系统会自动检查该项是否被其他数据引用。如果正在使用中，会**阻止删除**并显示使用情况。

| 字典分组 | 引用表 | 引用列 |
|----------|--------|--------|
| 问题分类 | `issues` | `category` |
| 发现阶段 | `issues` | `detectionPhase` |
| 严重度 | `issues` | `severity` |
| 关闭理由 | `issues` | `closeReason` |
| 组织类型 | `orgUnits` | `unitType` |

**示例：** 删除"功能 (function)"时，如果有 3 条 Issue 的分类为 `function`，则返回：
> 无法删除：Issue 问题分类: 3 条

## 推荐实践

1. **新项目启动**：先点「汽车默认值」再点「软件默认值」，保留两套值的并集；重复项自动跳过
2. **汽车电子团队**：汽车默认值已覆盖 IATF 16949 基本分类需求，软件默认值作为补充
3. **纯软件团队**：只用「软件默认值」即可，汽车相关项可手动删除

## 预设文件位置

预设定义在 `packages/server/src/service/DictService.ts` 的 `DICT_PRESETS` 常量中。如需自定义预设，直接编辑该文件即可。
