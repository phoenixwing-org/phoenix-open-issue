# 规则与约定

open-issue 开发过程中的设计决策和规则沉淀。

---

## 壳层架构

### 路由 vs Tab
- 应用壳层由 `AppShell.vue` 统一管理
- 页面导航走 **Workbench Tab 系统**，不直接 `router.push`
- Ribbon 按钮点击 → `openTab(pageId, title, contextKey)` → 自动创建/复用 Tab
- 同 UUID 的页面（如列表详情）只保留一个 Tab，激活已有而非新建

### 欢迎页
- 登录后默认进入仪表盘（`/dashboard`）
- 欢迎页通过 **全屏遮罩**（PnwAppModalOverlay）形式呈现，`panel-class="welcome-modal"` 设 960px 宽
- 点击左上角品牌 Logo → 弹出欢迎页（`showWelcome = true`）
- **关闭全部 Tab → 直接跳默认页**（不弹欢迎页，更直接）
- **返回工作空间 → 仅关闭遮罩**（无导航，自然显示背后的页面）
- "进入仪表盘" → 关闭遮罩 + 跳转 dashboard

### 模块划分
- Issue 模块：仪表盘、列表管理、推送历史
- 系统模块：组织架构、设置
- 左侧导航由 Ribbon 替代（PnwSidebarBlock 仅作辅助面板）

### 页面状态保持
- `router-view` 使用 `<KeepAlive :max="10">` 保持组件状态
- `:key="$route.fullPath"` 确保不同 UUID 各自缓存

## phoenix-wing 使用约定

### 组件导入路径
```ts
// 弹窗/覆盖层
import PnwAppModalOverlay from 'phoenix-wing/components/PnwAppModalOverlay.vue'
import PnwChoiceDialogHost from 'phoenix-wing/components/PnwChoiceDialogHost.vue'

// 壳层布局
import PnwRibbonShell from 'phoenix-wing/layout/PnwRibbonShell.vue'
import PnwSidebarBlock from 'phoenix-wing/layout/PnwSidebarBlock.vue'
import PnwPageHeader from 'phoenix-wing/layout/PnwPageHeader.vue'

// Composable
import { pnwPromptChoice, usePnwDocumentTitle } from 'phoenix-wing'
```

### 对话框
- 确认对话框：`pnwPromptChoice({ title, message, choices })` → 统一替代 ElMessageBox.confirm
- 消息提示：`pnwAlert(title, message)` → 替代 ElMessageBox.alert
- 文本输入：`pnwPromptInput(title, message)` → 替代 ElMessageBox.prompt

### Tab 管理
- 暂时使用 AppShell 内置的简化版 `openTab/closeTab/selectTab`
- 后续接入 `pnwCreateWorkbench` 引擎获得 session 恢复能力

### CSS
- 不覆写 phoenix-wing 组件的内部样式（scoped 隔离）
- 通过 CSS 变量自定义主题（`--phoenix-*`）

## 命名规则

phoenix-wing 所有公共 API 使用前缀，本应用无需前缀：
- 引用时使用 `Pnw`/`pnw` 前缀名
- 自定义组件/函数不需要加前缀（应用内部）

---

## 用户禁用行为约定

- 禁用用户**不能登录**
- 列表/详情/点检等**已分配该用户的展示**必须正常显示姓名（`getAllUsers({ includeDisabled: true })`）
- 新建/编辑表单的**用户下拉选择**必须排除禁用用户（`activeUsers = allUsers.filter(u => !u.disabled)`）
- 成员管理中添加成员下拉同样排除禁用用户

---

## 工作台标签同步

- 默认路由 `/` → 重定向到 `/dashboard`（仪表盘），不是欢迎页
- 欢迎页仅通过左上角 Logo 点击弹出（模态遮罩）
- 路由变化时自动同步 workbench 标签：
  - 无匹配标签 → 自动 `openTab`（如初始进入、关闭全部标签后）
  - 有匹配标签 → `activateTab` 高亮
- 关闭全部标签 → 回到仪表盘
