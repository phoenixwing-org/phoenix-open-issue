# 代码规范

## 命名规范

### SQL 列名 / JSON 字段 → `camelCase` 小驼峰

```sql
-- ✅ 正确
CREATE TABLE issues (
  issueNo TEXT,
  reporterId TEXT,
  detectionPhase TEXT,
  createdAt TEXT,
  updatedAt TEXT
);

-- ❌ 错误
CREATE TABLE issues (
  issue_no TEXT,
  reporter_id TEXT
);
```

```json
// ✅ 正确
{ "issueNo": "ISS-2026-0001", "reporterId": "uuid-xxx", "createdAt": "2026-06-30" }

// ❌ 错误
{ "issue_no": "ISS-2026-0001", "reporter_id": "uuid-xxx" }
```

### 函数 / 变量 → `camelCase` 小驼峰

```ts
// ✅ 正确
function getIssues(listId: string): Issue[] { }
const currentIssue = ref<Issue | null>(null)

// ❌ 错误
function get_issues(list_id: string): Issue[] { }
const current_issue = ref<Issue | null>(null)
```

### 类 / 接口 / 组件 / 枚举 → `PascalCase` 大驼峰

```ts
// ✅ 正确
class IssueService { }
interface CreateIssueInput { }
const LoginView = defineComponent({ })
type DetectionPhase = 'incoming' | 'in_process' | ...

// ❌ 错误
class issueService { }
interface createIssueInput { }
```

### REST API 路径 → `kebab-case`

```
✅ GET  /api/issue-lists
✅ POST /api/org-units
✅ GET  /api/list/:id/issues

❌ GET  /api/issueLists
❌ POST /api/org_units
```

### 文件名 → `kebab-case`

```
✅ issue-service.ts
✅ login-view.vue
✅ open-issue-core/

❌ IssueService.ts
❌ LoginView.vue
```

### 数据库表名 → `camelCase` 小驼峰

```sql
✅ issueLists, issueListMembers, pushRecords, orgUnits
❌ issue_lists, issue_list_members, push_records, org_units
```

---

## 前端后端一致性规则

**前后端之间传递的 JSON 字段名必须与 SQL 列名一致，均为 `camelCase`。**

- TypeScript 接口定义 → `camelCase`
- 前端 API 调用 → `camelCase`
- JSON request/response body → `camelCase`
- SQL 列名 → `camelCase`
- node-sqlite3-wasm `SELECT *` 返回的列名自然匹配 TS 接口

**禁止混用 snake_case 和 camelCase 在不同层之间。**
