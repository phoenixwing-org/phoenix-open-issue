# 界面巡游计划

## 实现状态

✅ 已完成。`driver.js` 驱动的壳层巡游 + 各页面帮助弹窗 + 本页导引。

## 技术方案

| 项 | 选择 |
|----|------|
| 巡游库 | `driver.js` |
| 壳层巡游 | `src/composables/useShellTour.ts` — 5 步 |
| 页面帮助 | `src/content/pageHelp.ts` — 集中管理各页帮助文本 + 本页导引步骤 |
| 帮助入口 | 每个页面 header 右侧 `?` 按钮（`PageHelpButton` 组件） |
| 总览入口 | 欢迎页「界面巡游」按钮 → 关闭遮罩 → 启动壳层巡游 |

## 壳层巡游步骤

```
1. Ribbon 功能切换 → Issue / 系统模块入口
2. Ribbon 快捷操作 → 当前模块的常用功能按钮
3. 工作台标签栏 → 已打开页面标签，支持切换和关闭
4. 主内容区 → 所有页面内容，右上角 ? 帮助按钮
5. 状态栏 → 当前页面名称，点击展开日志面板
```

## 各页面帮助与导引

| 页面 | 帮助要点 | 导引步骤 |
|------|----------|----------|
| welcome | 功能卡片概览 | 品牌区 → 功能卡片 |
| dashboard | 列表卡片操作、视图切换、新建列表 | 视图切换 → 新建列表 → 列表卡片 |
| lists | 列表总览表格、新建列表、编辑/删除 | 新建列表 → 列表总览 |
| listDetail | 三视图、筛选栏、Issue 表格、作废/恢复、推送 | 成员管理 → 新建 Issue → 筛选栏 → 视图模式 → Issue 表格（5 步） |
| issueDetail | Issue 字段、点检时间线、编辑/推送、页面模式 | 编号与状态 → 基本信息 → 点检时间线 |
| org | 组织树、成员管理、用户审批、禁用/启用 | （暂无导引步骤） |
| pushHistory | 推送记录查看、审批操作 | （暂无导引步骤） |
| settings | 数据字典、预设值、批量删除、备份 | 字典操作栏 |

## 使用方式

- **壳层巡游**：欢迎页 → 点击「界面巡游」→ 全屏 5 步导引
- **页面帮助**：任意页面 → 点击 header 右侧 `?` → 弹出帮助面板
- **本页导引**：帮助面板 → 点击「本页导引」→ driver.js 逐步指引
