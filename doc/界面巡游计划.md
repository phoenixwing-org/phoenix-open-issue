# 界面巡游计划

## 目标

为 Open Issue List 添加界面巡游（Guided Tour）功能，帮助新用户快速了解各个页面的功能。

参考 phoenix-desk-tools 的 `useShellTour` + `pageHelp` 模式。

## 技术方案

| 项 | 选择 |
|----|------|
| 巡游库 | `driver.js`（与 desk-tools 一致） |
| 帮助内容 | `src/content/pageHelp.ts` — 集中管理各页帮助文本 |
| 触发入口 | ① 页面 header 右侧 `?` 按钮 ② 欢迎页「巡游总揽」 |

## 实现步骤

### Step 1: 安装依赖
- [ ] `pnpm add driver.js`（web 包）

### Step 2: 创建页面帮助内容
- [ ] `packages/web/src/content/pageHelp.ts`
- 导出 `PAGE_HELP` 映射：pageId → { title, bullets, tourSteps? }
- 覆盖页面：welcome, dashboard, lists, listDetail, issueDetail, org, pushHistory, settings

### Step 3: 创建帮助按钮组件
- [ ] `packages/web/src/components/PageHelpButton.vue`
- 使用 `el-popover` 展示当前页帮助内容
- 若有 `tourSteps`，显示「本页导引」按钮

### Step 4: 各页面添加 `?` 按钮
- [ ] 每个使用 `PnwPageHeader` 的页面，在 `#help` 插槽放入 `PageHelpButton`
- PnwPageHeader 已有 `#help` 插槽（grid 最右列），无需改 wing 组件

### Step 5: 欢迎页巡游总揽
- [ ] 在 `WelcomeView` 添加「界面巡游」按钮
- 点击后：关闭遮罩 → 进入仪表盘 → 启动全壳层巡游

### Step 6: 壳层巡游
- [ ] 创建 `src/composables/useShellTour.ts`
- 定义全局壳层巡游步骤（Ribbon、Tab 栏、主内容区）
- 欢迎页「界面巡游」触发全壳层巡游

## 页面 `?` 帮助内容设计

| 页面 | 帮助要点 |
|------|----------|
| dashboard | 列表卡片操作、视图切换、新建列表、演示数据 |
| lists | 简单/复杂/跟踪三视图、筛选排序、新建 Issue |
| listDetail | 同上（与 lists 共用或单独） |
| issueDetail | Issue 字段说明、点检操作、状态流转 |
| org | 组织树浏览、成员查看 |
| pushHistory | 推送记录查看、状态说明 |
| settings | 系统配置项说明 |

## 巡游步骤（壳层）

```
1. Ribbon Tab → "功能切换：Issue / 系统"
2. Ribbon 工具按钮 → "打开仪表盘、列表管理等"
3. 主内容区 → "当前页面的工作区域"
4. 状态栏 → "底部显示当前页面名称"
```
