# Phoenix Admin 插件迁移审计

状态：template active / Issue interim

详细审计底稿和多插件纵向统计后续放到 `phoenix-ai-workspaces`；本文件只保留源码仓库需要共同遵守的统计口径、当前 Issue 快照和验收结论。

## 1. 统一报告模板

每个迁移项目必须按相同顺序报告，并把数字标为“实测”“估算”或“待测”。

### A. 身份与基线

- 项目、插件 `moduleId`、版本；
- 不可变 legacy commit；
- Host、Wing、COOL 兼容版本；
- 统计日期和复算命令。

### B. UI 保真

- legacy 与插件的路由 View 数、业务组件数和 UI 源码行数；
- template/style 完全一致数、允许差异数、未经批准差异数；
- 浏览器截图和关键交互回归结果；
- 未迁移页面及其归属理由（插件、Host、淘汰）。

### C. 算法与单元测试

- 迁移的纯算法文件/行数；
- 继承、增加、删除的测试文件和测试用例数；
- 算法是否仍依赖 Vue、Host、网络或数据库；
- 类型检查、单测、契约测试和构建结果。

### D. 框架复用

逐项列出身份、用户、部门、字典、文件、路由、菜单、权限、审计、任务、备份和 Wing 区域贡献：

1. legacy 自建实现；
2. COOL/Wing/Pah 替代能力；
3. 插件保留的 adapter；
4. 被消除的文件/行数；
5. 仍需插件拥有的领域规则；
6. 验证证据。

### E. 规模与交付物

必须同时报告，不能把其中一种体积冒充另一种：

- 源码文件数、物理行、非空行、UTF-8 字节；
- 插件压缩包大小；
- 安装后磁盘大小；
- 前端增量 chunk 原始/gzip/brotli；
- 后端产物与 migration 大小；
- peer dependency 与实际被重复打包的 dependency；
- 新增 Host adapter 成本与未迁移平台壳收益。

### F. 复杂度趋势

- 本插件从零搭建耗时；
- 使用共享脚手架后新增一个 View、API、Entity 的改动文件数；
- 相比前一个插件，专用 adapter 行数和重复配置是否下降；
- 每千行业务代码的测试用例数；
- 下一插件可直接复用的脚本、Fixture、Action 或 npm 包。

### G. 结论

- `pass`：UI/算法/关键交互无未解释回退，接口闭环，数字可复算；
- `conditional pass`：迁移切片已验证，但后端或交付包仍有明确待办；
- `fail`：重做 UI、丢算法、复用造成领域语义损失，或统计不可复算。

## 2. Issue 当前审计快照

结论：`conditional pass`。列表、Issue、点检和 Function 的 Midway 纵切已形成；Function 与单元测试 View 已原样迁入。推送、8D、仪表盘任务、字典写入、数据修正和正式插件交付包尚未闭环。

补充证据：

- 29 个 Vue 文件的 template/style 与 `legacy/2cdc5ea` 逐文件完全一致；其中 Function 简表和 Open Issue 单元测试入口均按 legacy 原样迁入；
- Admin 运行时已消费 Wing `eb131a4`：Ribbon 未选中项 computed color 为 `#64748b`，当前项为 `#1d4ed8`，图标继承按钮颜色且所有 `pnw:*` 均无 fallback；线框/实心图标的视觉重量另行验收；
- 5 个 legacy 算法文件原样纳入；加上 Midway 的纯 `domain/*.ts` 后当前共有 11 个纯领域/算法文件。3 个继承算法测试文件共 55 项；加入 Midway 领域、字典适配、修正规划和受控 runner 测试后，插件门禁实测 9 文件、84/84 项通过；
- 独立 App、main、Router、AppShell、Login 和 OAuth 共 7 个平台壳文件未进入插件；
- 6 个 Host adapter 是当前复用成本，不能从“省掉的代码”中隐去；
- 当前前端业务依赖闭包比 legacy 少 158 个物理行；后端新增代码和测试已另计入插件源码包，不能把前端净减少冒充完整收益；
- 审计脚本调用 `npm pack --dry-run` 实测源码交付包 107,142 bytes（约 104.6 KiB），解包 414,563 bytes，99 项，bundled dependencies 为 0；测试、Fixture、Vitest 缓存和 `node_modules` 不进入包；
- 该尺寸仍不是最终发布体积：推送、8D、仪表盘任务和数据修正等 Midway 业务尚未全部迁入，前端增量 chunk 也未单独计量，必须在正式构建后追加报告。

## 3. 当前复用收益判定

| 能力 | 当前收益 | 证据等级 |
| --- | --- | --- |
| 登录与会话 | 不迁移 Login/OAuth/AppShell；actor 由 Host adapter 提供 | 已实测 |
| 用户 | 复用 COOL 用户 list/update，插件不建第二份平台用户 | 前端已实测，后端待闭环 |
| 路由与导航 | 技术 ID 与短产品 URL 解耦；页内导航由 Host Router 承担 | 已实测 |
| Wing Layout | 复用 Admin Wing 0.6 壳，只迁 View Contribution | 已实测 |
| 数据字典 | COOL 负责 namespaced 存储；重要度/紧急度和核心 listType 由插件 adapter 强制协议值，非法 Host 项不会进入页面 | 只读适配与测试已实测，管理写入待闭环 |
| Function | legacy View 原样迁入，插件拥有 `oip_function`，Issue 继续引用稳定 functionId；XLSX 使用 Host peer dependency | 浏览器已真实创建 `MIG-001` 并打开编辑弹窗；用户点检待复核 |
| 单元测试 | legacy View 原样迁入；本地 runner 仅执行固定插件脚本，不接收客户端命令/路径，生产默认不可用 | 浏览器实测识别 9 文件/84 用例并运行 84/84 通过；用户点检待复核 |
| 部门、文件、审计、任务、备份 | Host 有能力入口，插件 adapter 与数据边界未完成 | 待研究 |

最终审计必须把“已实测”和“计划复用”分开，不能提前把待办计入收益。
