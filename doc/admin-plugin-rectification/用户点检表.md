## 9. 本地卸载与恢复

完成本轮开发或需要证明 Host 可脱离插件运行时：

```bash
pnpm admin-plugin:unmount-dev-host
```

- [ ] 只删除两条插件源码软链接和插件创建的依赖软链接；
- [ ] 两仓 `.git/info/exclude` 中的本插件标记被移除；
- [ ] Vue/Node Host 重启后仍能独立运行；
- [ ] `/pah/plugins` 中先停用或卸载本地登记，避免留下不可加载菜单；
- [ ] 需要恢复时重新执行 mount、重启 Host、启用插件即可。
