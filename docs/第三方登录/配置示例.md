# 第三方登录配置示例

## 服务端环境变量

以下配置已经由服务端支持。不要把真实密钥提交到仓库：

```dotenv
# 第三方登录总开关。关闭时 /api/auth/providers 不返回任何提供方。
THIRD_PARTY_LOGIN_ENABLED=false
THIRD_PARTY_ACCOUNT_MODE=bind_existing

# 飞书提供方开关和应用凭据。
FEISHU_LOGIN_ENABLED=false
FEISHU_APP_ID=
FEISHU_APP_SECRET=

# 必须与飞书开放平台应用安全设置完全一致；生产环境使用 HTTPS。
FEISHU_REDIRECT_URI=https://issues.example.com/api/auth/oauth/feishu/callback

# 逗号分隔的允许租户 tenant_key。生产环境启用飞书登录时不得为空。
FEISHU_ALLOWED_TENANT_KEYS=tenant_key_1

# 登录只申请基础身份信息；没有业务需要时保持为空，不申请 offline_access。
FEISHU_SCOPES=

# 前后端分离时填写前端根地址；一体部署生产环境留空，使用同域回调页。
WEB_BASE_URL=https://issues.example.com

# OAuth 事务和前端一次性登录票据有效期。
OAUTH_STATE_TTL_SECONDS=600
OAUTH_TICKET_TTL_SECONDS=120

```

## 不属于配置的值

以下值每次登录都会变化，不能写入 `.env`：

- OAuth `state`
- 飞书回调返回的授权码 `code`
- 飞书 access token / refresh token
- 本项目一次性登录票据

这些值只在一次 OAuth 事务中使用，并且必须短期有效、单次消费、禁止日志记录。

## 飞书开放平台设置

1. 创建或选择企业自建应用。
2. 取得 App ID 和 App Secret，App Secret 只配置在服务端。
3. 在安全设置中添加与 `FEISHU_REDIRECT_URI` 完全一致的重定向地址。
4. 只开通登录需要的最小权限，完成应用发布或租户内可用配置。
5. 确认应用可访问的租户，并把 `tenant_key` 写入允许列表。
6. 开发、测试、生产使用不同应用和不同回调地址，避免密钥及测试身份串用。

## 启动时校验

满足以下任一情况时，服务端应拒绝启动或自动禁用飞书登录并打印不含密钥的明确错误：

- 总开关已开启，但飞书 App ID、App Secret 或回调地址缺失。
- 生产环境启用飞书登录，但回调地址不是 HTTPS。
- 生产环境启用飞书登录，但允许租户列表为空。
- 登录权限包含 `offline_access`（首期不保存 refresh token，因此禁止申请）。
- 生产环境配置了非 HTTPS 的 `WEB_BASE_URL`。
- 账号模式不是服务端当前支持的枚举值。

前端不需要、也不允许配置 App Secret。登录按钮是否显示应由 `/api/auth/providers` 的服务端响应决定，不能只依靠前端环境变量。
