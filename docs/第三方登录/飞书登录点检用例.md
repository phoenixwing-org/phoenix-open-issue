## TC-01 登录页出现飞书入口

**目的**：确认第三方登录对用户可见。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开登录页（未登录） | 页面正常 |
| 2 | 查看登录区下方 | 有「使用飞书登录」按钮 |
| 3 | 本地账号表单仍可见 | 用户名/密码可填 |

- [x] 通过

---

## TC-02 取消授权可安全返回

**目的**：用户在飞书侧取消时，本系统无脏数据。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 点击「使用飞书登录」 | 跳转飞书授权页 |
| 2 | 在飞书页取消/拒绝授权 | 回到本系统回调页 |
| 3 | 阅读提示 | 提示已取消或授权未完成，**不是**登录成功 |
| 4 | 点返回登录 | 回到登录页；无新会话 |

- [x] 通过

---

## TC-03 未绑定 → 待审查（新人路径）

**目的**：未绑定飞书账号不自动建号，进入待审查。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 退出本系统；用 **UserA** 的飞书点「使用飞书登录」并同意授权 | 进入「已提交待审查」页（非进入首页） |
| 2 | 查看飞书姓名/邮箱展示 | 有飞书侧信息（或「—」） |
| 3 | 填写拟用用户名、拟用姓名 → 保存 | 提示已保存/等待管理员 |
| 4 | 确认 **未** 进入系统（无 Dashboard） | 无有效登录态 |
| 5 | Admin 打开 **组织架构** | 顶部「第三方登录待审查」有一条（UserA） |

- [x] 通过

---

## TC-04 管理员绑定已有本地账号

**目的**：老用户未绑飞书时，管理员绑到已有账号。

前置：完成 TC-03，或另用未绑定飞书再登一次产生待审查；本系统已有 **UserB**（已批准）。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | Admin 在待审查点「处理」 | 弹出处理对话框 |
| 2 | 选择「绑定已有账号」，选中 **UserB** → 确认 | 提示绑定成功；待审查列表该条消失 |
| 3 | 退出 Admin；用该飞书账号再点「使用飞书登录」 | 登录成功，进入系统 |
| 4 | 打开设置 → 登录方式 | 显示已绑定飞书身份；当前用户为 UserB |

- [x] 通过

---

## TC-05 管理员新建账号并绑定

**目的**：无本地账号时，管理员新建并绑定。

前置：用 **UserC** 飞书登录产生一条新的待审查（勿与 TC-04 同一飞书身份）。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | Admin 处理该条 →「新建账号并绑定」 | 可填用户名、姓名、初始密码 |
| 2 | 输入 **已存在** 用户名（如 `admin`）点确认 | 前端或接口提示用户名不可用/已存在 |
| 3 | 改用全新用户名 + 密码（≥6 位）→ 确认 | 创建成功；待审查消失 |
| 4 | 用该飞书再登录 | 进入系统；账号为新建用户 |
| 5 | （可选）用新建用户名 + 初始密码本地登录 | 可登录（本地方式仍开启时） |

- [x] 通过

**目的**：普通用户不能自己绑飞书。

## TC-07 解除绑定后再登回到待审查

**目的**：解绑后不能继续飞书登录，需重新审批绑定。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 已绑飞书用户在设置 → 登录方式点「解除绑定」并确认 | 提示成功；状态为已解除或列表无 active |
| 2 | 退出；再用同一飞书登录 | **不能**直接进系统；再次进入待审查 |
| 3 | Admin 组织页 | 出现新的待审查记录 |

- [x] 通过

## TC-08 登录方式开关（仅管理员）

**目的**：全站本地 / 第三方 checkbox 生效。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | Admin → 设置 → 登录方式顶部 | 可见「本地账号密码」「第三方登录」两个勾选框 |
| 2 | 只勾「本地」，取消「第三方」→ 保存 | 保存成功 |
| 3 | 无痕打开登录页 | **无**飞书按钮；本地表单仍在 |
| 4 | 恢复双勾；再只勾「第三方」，取消「本地」→ 保存 | 保存成功 |
| 5 | 无痕打开登录页 | **无**用户名密码表单（或不可提交）；有飞书按钮 |
| 6 | 尝试两个都取消 → 保存 | **不能**保存（提示至少保留一种） |
| 7 | 恢复「本地 + 第三方」勾选并保存 | 登录页两种入口都在 |

- [x] 通过
