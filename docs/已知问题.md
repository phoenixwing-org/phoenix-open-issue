## Wing 聚合 UI singleton 双实例（Open Issue 侧已关闭）

现象：`pnwPromptChoice` 等模块级状态在 Vite 预打包入口和聚合包内部 `.vue` 相对导入之间形成两个实例，调用方写入的 `ref` 与 Host 读取的 `ref` 不同。

0.4.1 的 workaround 曾位于 `packages/web/vite.config.ts`：

```ts
optimizeDeps: {
  exclude: ["phoenix-wing"],
},
```

0.4.2 已提供统一编译出口，本仓已删除该配置。关闭证据：

1. Wing 聚合 UI 提供编译后的统一 JS/d.ts 出口，内部和外部 import 命中同一模块实例。
2. Registry 测试确认根入口和 composable 子路径共享同一对话框状态，并使用随包 Ribbon v1 fixture 验证未知 schema 被拒绝。
3. Open Issue 自动测试和 production build 通过。Desk bundler consumer 仍需独立升级验收，联合 R2 在此之前不计分。

原始排查过程保存在 `BUG日志.md`，由文档清单标记为 superseded。
