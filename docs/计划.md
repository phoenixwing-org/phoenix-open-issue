# phoenix-open-issue 计划

## 项目定位

基于 phoenix-wing 框架搭建的 **Open Issue 管理应用**。
作为 phoenix-wing 框架的首个独立应用案例，验证框架的复用性和完整性。

## 技术栈

- Vue 3 + TypeScript + Vite
- phoenix-wing（壳层框架 + 控件库）
- Element Plus + Pinia

---

## 架构：搭积木

`index.vue` 作为顶层壳，用 phoenix-wing 组件直接拼出完整应用：

```
┌─ AppToolbar ──────────────────────────────────────────┐
│ [Brand]  PnwRibbonTabBar  PnwWorkbenchTabBar(inHeader) │
├─ PnwRibbonShell ──────────────────────────────────────┤
│   PnwRibbonGroup → PnwRibbonToolButton × N             │
├─ main ────────────────────────────────────────────────┤
│ ┌─ PnwSidebarBlock ─┐ ┌─ <router-view> ────────────┐  │
│ │ · 筛选面板         │ │                              │  │
│ │ · 属性面板         │ │   IssueListPage / DetailPage │  │
│ └───────────────────┘ └──────────────────────────────┘  │
├─ StatusBar ───────────────────────────────────────────┤
│   PnwShellLogPanel                                     │
└───────────────────────────────────────────────────────┘

全局层:
  PnwAppModalOverlay     ← 配置弹窗
  PnwChoiceDialogHost    ← 确认对话框
  PnwAsyncProgressOverlay ← 异步进度
```

**index.vue 伪代码：**
```vue
<template>
  <PnwAppModalOverlay :open="configOpen" @close="configOpen = false">
    <ConfigPage />
  </PnwAppModalOverlay>
  <PnwChoiceDialogHost />
  <PnwAsyncProgressOverlay />

  <div class="shell">
    <AppToolbar />
    <PnwRibbonShell :collapsed="ribbonCollapsed">
      <RibbonPanel />
    </PnwRibbonShell>
    <main>
      <PnwSidebarBlock title="筛选" collapsible>
        <FilterPanel />
      </PnwSidebarBlock>
      <router-view />
      <PnwSidebarBlock title="属性" variant="card">
        <PropertyPanel />
      </PnwSidebarBlock>
    </main>
    <StatusBar>
      <PnwShellLogPanel :log-text="log" @clear="clearLog" @close="logOpen = false" />
    </StatusBar>
  </div>
</template>
```

## 欢迎页

### 需求

欢迎页是用户首次进入应用或通过工具栏触发的入口页面，核心目的是**引导用户了解系统功能**并**快速进入工作台**。

### 展示方式

| 场景 | 展示方式 | 说明 |
|------|----------|------|
| 首次访问（根路径 `/`） | **路由重定向** → `PnwAppModalOverlay` 遮罩弹出 | 路由 `/` → `/welcome`，WelcomeView 作为 `<router-view>` 子路由渲染。同时 AppShell 可通过 `showWelcome` 以遮罩方式再次唤醒 |
| 工具栏触发 | **PnwAppModalOverlay** 遮罩弹出 | 点击工具栏 Brand 按钮 → `showWelcome = true`，以半透明遮罩 + 居中面板展示，点击遮罩或关闭按钮可关闭 |
| 用户已登录再次访问根路径 | **重定向到仪表盘** | `router.beforeEach` 检测已有 token → 跳转 `/dashboard` |

### 页面结构

使用 `PnwWelcomeShell` 骨架，分为四个插槽区域：

```
┌─ PnwWelcomeShell ────────────────────────────────────────┐
│ ┌─ left rail ──┐ ┌─ main ─────────────────────────────┐ │
│ │ #brand        │ │ #title                             │ │
│ │ (品牌标识)     │ │ #headActions [打开仪表盘] [✕]      │ │
│ │               │ ├────────────────────────────────────┤ │
│ │ #actions      │ │ #main                              │ │
│ │ [返回工作台]   │ │ 功能卡片（列表管理/Issue追踪/推送）  │ │
│ │               │ │                                    │ │
│ │ #links        │ │                                    │ │
│ │ (外链)         │ │                                    │ │
│ └───────────────┘ └────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

### 按钮行为

| 按钮 | 位置 | 行为 |
|------|------|------|
| **返回工作台** | 左侧栏 `#actions` 插槽 | 关闭遮罩（`emit('close')`），回到下方已有的工作台页面 |
| **打开仪表盘** | 右侧头部 `#headActions` 插槽 | 关闭遮罩 + `router.push('/dashboard')`，显式导航到仪表盘 |
| **✕ 关闭** | 右侧头部 `#headActions` 插槽 | 关闭遮罩，停留在当前页面 |

### 组件关系

```
AppShell.vue
  ├─ <router-view> → WelcomeView（路由 /welcome 时渲染）
  │                    └─ PnwWelcomeShell
  └─ PnwAppModalOverlay(showWelcome)
       └─ WelcomeView（遮罩方式复用同一组件）
            └─ PnwWelcomeShell
```

`WelcomeView.vue` 同一组件可用于**路由页**和**遮罩弹窗**两种模式，通过 `emit('close')` 通知父组件关闭遮罩。当作为路由页渲染时，`close` 事件无监听者即为空操作。
